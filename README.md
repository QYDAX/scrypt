# scrypt
NixOS helper, for when you don't want to type out long commands.
Prerequesites:
Must have python installed
Obviously only works on a nixos system
Run via python /pathtoscript/scrypt.py, which depends on where you want to save it.
I use it via a keybind that launches it in alacritty via my hyprland lua configuration, although you can configure similar keybinds in other WMs and DEs.
